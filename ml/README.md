# 数据驱动代理模型（ml/）

在效率 MAP 机理模型之上叠一层数据驱动代理模型，用于回答两个工程问题：

1. 机器学习模型能多准确地复现机理模型的净能耗结论？
2. 在什么范围内可以拿代理模型替代机理模型做大规模工况筛选？

## 目录

| 文件 | 作用 |
|---|---|
| `data.py` | 工况随机采样、特征工程（26 维）、数据集与分布外压力测试集构建 |
| `models.py` | 纯 numpy 实现的岭回归（闭式解）与 MLP（Adam），不依赖 scikit-learn |
| `train_eval.py` | 训练、评测、分工况误差、分布外泛化、特征重要性、badcase、速度基准，并生成报告 |
| `report.md` | 自动生成的对比实验报告 |
| `metrics.json` | 全部指标的机器可读版本 |
| `test_predictions.csv` | 测试集逐条预测结果 |

## 运行

```bash
python -m ml.train_eval
```

约 30 秒完成，输出写入本目录。

测试：

```bash
python -m pytest tests/test_ml_pipeline.py -q
```

## 方法说明（重要）

标签由**效率 MAP 机理模型**生成，因此本任务是**代理建模（surrogate modeling）**，目标是逼近机理模型，而不是逼近实车实测能耗。这个定位必须讲清楚：

- 可以说："代理模型把机理模型的结论继承到微秒级推理，用于调度优化中的粗筛。"
- 不能说："我的模型能预测真实矿卡能耗。"

要跨越到真实预测，需要实测数据做标定，这是后续工作。

## 主要结果（一次可复现运行）

| 模型 | MAE (kWh) | MAPE | R² |
|---|---|---|---|
| 恒定效率 90%（物理假设参照系） | 1.749 | 16.13% | 0.9638 |
| 岭回归（线性代理） | 0.920 | 11.76% | 0.9924 |
| MLP 64-32（非线性代理） | 0.162 | 2.23% | 0.9998 |

- 分工况：平路 MAPE 3.03% 最差，重载上坡 1.07% 最好（MAPE 以净能耗为分母，量级差异导致）
- 分布外外推：MLP 的 MAPE 由 2.23% 升至 10.68%（4.8×），说明替代边界存在
- 推理加速：单次评估 0.15 ms → 0.0006 ms，两个数量级（数值与机器负载相关，报告里只作量级结论）
